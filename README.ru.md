# Phone — ADB + scrcpy для Omarchy

[English](README.md) | **Русский**

Виджет на панели и CLI для зеркалирования Android-телефона по Wi-Fi. Телефон
раздаёт хотспот, поэтому его адрес — шлюз по умолчанию (тот же, что печатает
`ip route | grep default`). Плагин перечитывает адрес при каждом запуске, так
что переключение хотспота и смена IP не требуют ручных действий.

## Установка

Одна команда — пакеты, плагин, симлинк CLI, клавиши и правило окна, а в конце
проверка:

```bash
curl -fsSL https://raw.githubusercontent.com/FostikPts/omarchy-phone/main/install.sh | bash
```

Вручную — см. [INSTALL.ru.md](INSTALL.ru.md). Коротко:

```bash
omarchy pkg add android-tools scrcpy
omarchy plugin add https://github.com/FostikPts/omarchy-phone.git --enable
ln -sf ~/.config/omarchy/plugins/admin.phone/bin/omarchy-phone ~/.local/bin/omarchy-phone
```

Дальше добавить клавиши и правило окна (шаги 4–5 в INSTALL.ru.md) и проверить:

```bash
omarchy-phone doctor
```

**Плагин предполагает, что интернет раздаёт телефон** (то есть телефон — шлюз
по умолчанию). Если телефон просто в той же Wi-Fi сети, что и компьютер, один
раз спарьте его: `omarchy-phone pair`, затем `omarchy-phone mirror`.

## Состав

```
~/.config/omarchy/plugins/admin.phone/
├── manifest.json        # манифест виджета
├── Panel.qml            # иконка на панели и всплывающая панель
├── Model.js             # разбор статуса, подписи, список действий
└── bin/
    ├── omarchy-phone    # CLI (симлинк в ~/.local/bin/omarchy-phone)
    └── phone-watch.py   # сохраняет выбранный размер окна scrcpy
```

## CLI

```bash
omarchy-phone ip                # определённый IP телефона (шлюз по умолчанию)
omarchy-phone ip --notify       # то же, уведомлением
omarchy-phone status [--json]   # состояние для скриптов и виджета
omarchy-phone doctor            # проверка зависимостей, бинда, сети, телефона
omarchy-phone connect           # ADB по Wi-Fi
omarchy-phone disconnect        # отключить все Wi-Fi ADB
omarchy-phone mirror            # подключиться при необходимости и запустить scrcpy
omarchy-phone rotate            # переключить портрет/ландшафт (с фиксацией)
omarchy-phone rotate portrait   # принудительно портрет
omarchy-phone rotate landscape  # принудительно ландшафт
omarchy-phone rotate auto       # снова следовать акселерометру
omarchy-phone usb               # один раз: adb tcpip 5555 через USB-кабель
omarchy-phone pair [адрес] [код]  # беспроводная отладка (Android 11+)
omarchy-phone auto              # тихое переподключение (виджет и post-boot hook)
```

`connect` пробует по порядку:

1. адрес, который уже онлайн в `adb devices`;
2. mDNS-сервис для шлюза (беспроводная отладка Android 11+);
3. классический порт `5555`;
4. `adb tcpip 5555` по USB, если воткнут кабель.

Первый запуск на новом телефоне требует одной из двух настроек:

- **USB:** воткнуть кабель, разрешить отладку, затем `omarchy-phone usb`;
- **Беспроводная отладка (Android 11+):** включить на телефоне и выполнить
  `omarchy-phone pair` (пункт меню открывает терминал для кода).

## Окно зеркала и поворот

Окно scrcpy без рамки и плавающее (правило для класса `^scrcpy$` в
`~/.config/hypr/windows.lua`). Соотношение сторон задаёт телефон, при первом
запуске плагин подбирает под него размер окна.

Ни Wayland, ни Hyprland не дают клиенту менять размер или поворачивать своё
окно, поэтому `mirror` запускает `bin/phone-watch.py`. Он **не спорит с
пользователем**: меняйте размер и положение окна как удобно — оно останется
таким. Вотчер реагирует только на изменение самого экрана телефона (поворот
или смену разрешения), и тогда сохраняет длинную сторону окна и его центр, а
не возвращает окно в середину экрана. Окно следует и за физическим поворотом (при
включённом автоповороте), и за ручным `rotate` — обычно в пределах секунды.

Последний размер и позиция запоминаются в
`~/.local/state/omarchy-phone/geometry.json` и восстанавливаются следующим
`mirror`. `WINDOW_FIT=never` в `~/.config/omarchy-phone/config` полностью
отключает автоподгонку при повороте.

`omarchy-phone rotate` фиксирует ориентацию так же, как блокировка поворота:
переключает портрет и ландшафт. Заодно система просит Android игнорировать
запросы ориентации от приложений, поэтому работает и на экранах, зашитых в
портрет (лончер). `omarchy-phone rotate auto` возвращает управление
акселерометру и приложениям.

Экран телефона при зеркалировании остаётся включённым (`--stay-awake`, без
`--turn-screen-off`), иначе телефон перестал бы следовать акселерометру.

## Виджет

- левый клик — панель с IP, состоянием ADB, моделью и действиями, включая
  «Rotate phone screen» и «Follow phone rotation»;
- правый клик — сразу зеркалировать;
- тусклая иконка — нет подключения;
- статус опрашивается каждые 15 с, известный телефон переподключается после
  смены IP хотспота (отключается через `"autoReconnect": false` в записи
  виджета в `shell.json`).

## Меню

`SUPER + SPACE` → поиск «phone»: Mirror screen / Rotate screen / Follow phone
rotation / Connect / Disconnect / Show IP / Pair.

## Клавиши

| Клавиша | Команда |
|---|---|
| `SUPER + SHIFT + P` | `omarchy-phone mirror` — подключиться и зеркалировать |
| `SUPER + SHIFT + U` | `omarchy-phone usb` — включить ADB по Wi-Fi через USB-кабель |
| `SUPER + SHIFT + R` | `omarchy-phone view` — повернуть изображение на 90° |

Все три сообщают через десктоп-уведомления, терминал не нужен. Бинд Google
Photos переехал на `SUPER + ALT + P`.

`mirror` и сам поднимает USB, если нужно: когда кабель воткнут, а по Wi-Fi
телефон ещё недоступен, он сначала выполняет `adb tcpip 5555`. Клавиша `U`
нужна, чтобы сделать только этот шаг — включить Wi-Fi ADB один раз и вынуть
кабель.

## Настройки

`~/.config/omarchy-phone/config` (необязательно, `KEY=value`):

```bash
ADB_PORT=5555                                    # классический порт беспроводного adb
PHONE_IFACE=""                                   # принудительный интерфейс (например wlp3s0)
SCRCPY_ARGS="--stay-awake --window-title=Phone --window-borderless --shortcut-mod=lctrl"
AUTO_RECONNECT=1                                 # 0 отключает `omarchy-phone auto`
NOTIFY=1                                         # 0 отключает уведомления
WINDOW_FIT="rotate"                              # rotate | never (см. ниже)
```

`PHONE_IFACE` нужен только когда маршрутов по умолчанию несколько и
автоматический выбор беспроводного интерфейса ошибается (необычная настройка
VPN).

Состояние живёт в `~/.local/state/omarchy-phone/` (`state`, `geometry.json`,
`view`, `phone.log`).
`omarchy-phone disconnect` очищает состояние, что заодно останавливает
автопереподключение до следующего ручного подключения.

## Удаление

```bash
omarchy plugin remove admin.phone
rm ~/.local/bin/omarchy-phone
rm -rf ~/.local/state/omarchy-phone ~/.config/omarchy-phone
rm ~/.config/omarchy/hooks/post-boot.d/omarchy-phone-auto
```

## Поворот изображения (только картинка)

`omarchy-phone view [0|90|180|270]` поворачивает **изображение** внутри окна
scrcpy и не трогает телефон — в отличие от `rotate`, который меняет поворот
экрана Android, и в отличие от поворота самого телефона, который меняет то,
что видят камера и приложения.

Без аргумента добавляет 90° (`0 → 90 → 180 → 270 → 0`). Угол запоминается в
`~/.local/state/omarchy-phone/view` и используется всеми последующими
`mirror`. Так как scrcpy читает ориентацию только при старте, смена угла во
время зеркалирования пересоздаёт окно; вотчеру окна угол тоже передаётся,
поэтому он продолжает подгонять размер под повёрнутое изображение.

Клавиша: `SUPER + SHIFT + R` (`o.bind` в `~/.config/hypr/bindings.lua`).
В панели виджета четыре пресета показаны рядом чипов (0°, 90°, 180°, 270°);
текущий нарисован нажатым, повторно нажать его нельзя.

В панели клавиатура тоже достаёт до чипов: `↓` идёт по строкам действий и
затем входит в ряд пресетов, `←`/`→` выбирают пресет, `↑` возвращает назад,
`Enter` применяет выбранный.

## Живое состояние в панели

Две строки отражают телефон, а не просто команды:

- **Mirror screen** подсвечена, пока работает scrcpy, и показывает рабочий
  стол, на котором лежит окно (`workspace 4`);
- **Follow phone rotation** подсвечена, пока телефон следует акселерометру
  (`on`). Повторное нажатие фиксирует текущий поворот (`off`) вместо того,
  чтобы оставлять автоповорот — `wm user-rotation lock` без угла удерживает
  текущую ориентацию.

Командная строка: `scrcpy --display-orientation=<угол>`.
